Optional：消除層層的 null 檢查

沒有 Optional 之前

Java 8 之前，方法找不到值時通常回傳 null，但 API 本身看不出「這裡可能是 null」。為了避免 NullPointerException，呼叫端只好對每一層都檢查：

Optional 是一個「可能有值、也可能沒有值」的容器。方法回傳 Optional，就是明確告訴呼叫端：這裡可能沒有值。

什麼時候不要用 Optional

  1. 欄位：Optional 沒有實作 Serializable，不適合當類別的欄位。
