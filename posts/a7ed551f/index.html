2. 設定 NTP 對時

時間不準會影響 log 的時間戳、排程、TLS 憑證驗證和分散式系統之間的協作，所以一定要設定自動對時。

方法一：crontab 定時執行 ntpdate

CentOS 7 預設的對時服務其實是 chronyd。改用 ntpd 的話，要先停用 chronyd（systemctl disable --now chronyd），兩者同時執行會互相干擾。如果沒有特別需求，直接用 chronyd 也可以，chronyc sources 可以查看同步狀態。

4. 關閉 SSH root 遠端登入

讓 root 可以直接 SSH 登入，等於讓暴力破解只需要猜密碼。建議關閉，改用一般帳號登入後再 sudo。

⚠️ 關閉之前，先確認已經有可以 SSH 登入、而且有 sudo 權限的一般帳號，並另外開一個連線測試成功，避免把自己鎖在外面。
