用 Docker 架設 Oracle 資料庫：Windows Docker Desktop 與 Linux 的安裝、run 參數說明與 sqlplus 連線

發表於 2020-03-18 更新於 2026-11-27 分類於 Docker 閱讀次數： Disqus： 文章字數： 2.5k 所需閱讀時間 ≈ 5 分鐘

開發和 CI/CD 測試時，常需要一個本機的 Oracle 資料庫。這篇整理用 Docker 架設 Oracle 的兩種情境：在 Windows 用 Docker Desktop 匯入現成的 Oracle 11g 映像檔，以及在 Linux 上安裝 Docker、建立 Oracle container 並用 sqlplus 連線，每個 docker run 參數的意思都附上說明。

情境一：Windows + Docker Desktop

1. 安裝 Docker Desktop

到 https://www.docker.com/products/docker-desktop 下載並安裝 Docker Desktop for Windows。

2. 匯入 Oracle 映像檔

我們有一個打包好的 oracle11g.tar，用系統管理員權限開啟命令提示字元，切換到 tar 檔所在的目錄後匯入：

3. 啟動 container

參數說明
--privileged給 container 較高的權限，安裝 Oracle 時可能需要
--name oraclelocalcontainer 名稱
-d在背景執行（detached）
-p 11521:1521把 container 內的 1521 port 對應到主機的 11521 port（主機:container）
-e ORACLE_ALLOW_REMOTE=true允許從 container 外部連線
-v /home:/install把主機的 /home 掛載到 container 的 /install
/assets/entrypoint.sh啟動時執行的程式（用 docker import 匯入的映像檔沒有預設的啟動指令，要自己指定）

4. 確認啟動成功

情境二：Linux + Docker

在 Linux 上架 Oracle container，常用在 CI/CD 的整合測試。

1. 安裝 Docker

Rocky Linux 8 安裝時遇到套件衝突，請參考 在 Rocky Linux 8 安裝 Docker 與常見錯誤。

2. 下載 Oracle 映像檔

從 Docker Hub（https://hub.docker.com/ ）或 Oracle Container Registry 找到要用的映像檔：

3. 建立 container

參數說明
--namecontainer 名稱
--shm-size=1gLinux 共享記憶體大小，Oracle 需要足夠的共享記憶體
-p 1521:1521資料庫 listener port（主機:container）
-p 18080:8080管理介面的 port
-e ORACLE_PWDSYS、SYSTEM、PDBADMIN 的密碼
-v <volume_name>:/u01/app/oracle/oradata資料檔放在 volume。沒加的話，container 重建後資料就消失了

4. 進入 container 使用 sqlplus

Oracle 第一次啟動要初始化資料庫，可能需要好幾分鐘，可以用 docker logs -f <container_name> 看進度。

常用指令

指令說明
docker images -a查看本機的映像檔
docker ps -a查看所有 container（包含停止的）
docker stop oraclelocal停止 container（名稱或 ID）
docker start oraclelocal啟動已存在的 container
docker logs -f oraclelocal查看 container 的輸出
