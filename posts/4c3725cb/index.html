註冊 AWS 帳號步驟：建立帳號、付款與身分驗證、Support Plan，以及設定免費額度與帳單告警

發表於 2022-01-19 更新於 2026-11-27 分類於 AWS 閱讀次數： Disqus： 文章字數： 1.4k 所需閱讀時間 ≈ 2 分鐘

這篇整理註冊 AWS 帳號的完整流程：填寫帳號資訊、加入付款方式、電話驗證身分、選擇 Support Plan，以及最重要的一步：設定免費額度告警和 CloudWatch 帳單告警，避免不小心開了資源忘記關，月底收到大額帳單。

AWS 的註冊畫面會不定期改版，以下是我註冊時的流程，按鈕名稱可能略有不同。

階段一：建立帳號

  1. 到 AWS 首頁，點選 Create an AWS Account（如果最近登入過，會看到登入畫面，可以選擇登入其他帳號後再建立新帳號）
  2. 填寫帳號資訊。email 一定要填對，它就是 root 帳號的登入帳號，填錯就無法存取這個帳號
  3. 選擇帳號類型：Personal（個人）或 Professional（公司、學校、組織）。兩種功能完全相同，只是用途不同
  4. 填寫個人或公司資料
  5. 閱讀並勾選同意 AWS Customer Agreement，繼續下一步

階段二：加入付款方式

在付款資訊頁面加入信用卡等付款方式並驗證。沒有加入有效的付款方式，就無法完成註冊，即使只打算使用免費額度也一樣。

階段三：驗證身分

  1. 選擇國家或地區代碼，填入幾分鐘內能接聽的電話號碼
  2. 輸入 CAPTCHA 驗證碼
  3. 選擇用電話或簡訊接收驗證碼
  4. 輸入收到的驗證碼，完成驗證

階段四：選擇 Support Plan

選擇免費的 Basic Support，個人學習或測試就足夠了。完成後就可以登入主控台。

階段五：設定告警（非常重要）

1. 開啟免費額度與帳單告警

  1. 在主控台上方搜尋 Billing 並進入
  2. 左側選單選擇 Billing preferences
  3. 勾選 Receive Free Tier Usage Alerts（用量快超過免費額度時通知）和 Receive Billing Alerts（開啟帳單指標，才能在 CloudWatch 設定告警）
  4. 填入接收通知的 email，儲存設定

2. 用 CloudWatch 設定帳單金額告警

  1. 搜尋並進入 CloudWatch
  2. 把右上角的區域切換到 **US East (N. Virginia)**：帳單指標只存在這個區域，代表全球所有區域的費用
  3. 左側選擇 Alarms → Create alarm
  4. Select metric → 搜尋 Billing → 選擇 Billing → Total Estimated Charge（找不到的話，回到上一步確認已開啟 Billing Alerts，開啟後指標可能要等一段時間才會出現）
  5. 勾選 EstimatedCharges → Select metric
  6. 條件設定：
    • Threshold type：Static
    • Whenever EstimatedCharges is：Greater
    • than：你能接受的每月金額，例如 10（美元）
  7. 通知設定：
    • Alarm state trigger：In alarm
    • 選擇 Create new topic，輸入 SNS topic 名稱和接收通知的 email
    • 到信箱點擊確認訂閱，之後才會收到通知
  8. 輸入告警名稱和說明（名稱只能用 ASCII 字元），確認設定後 Create alarm

設定完成後，只要當月預估費用超過門檻，就會收到 email 通知。

註冊完成後的安全建議

  • 不要用 root 帳號做日常操作：建立 IAM 使用者（或使用 IAM Identity Center），只給需要的權限
  • 替 root 帳號開啟 MFA（多因素驗證）
  • 不要建立 root 帳號的 Access Key

IAM 權限的觀念可以參考 Developing on AWS 課程筆記。
