Docker 容器裡 bash: ip / ping: command not found 的解法

發表於 2023-05-12 更新於 2026-11-26 分類於 Linux 閱讀次數： Disqus： 文章字數： 1.3k 所需閱讀時間 ≈ 2 分鐘

進到 Docker 容器裡想查網路，卻出現 bash: ip: command not found 或 bash: ping: command not found。原因是為了讓映像檔盡量小，很多基礎映像檔都沒有內建這些網路工具。這篇整理在不同發行版要安裝哪個套件，以及怎麼避免每次重建容器都要重裝。

避免每次重建容器都要重裝

1. 寫進 Dockerfile

2. 不改映像檔，從主機或另一個容器除錯
