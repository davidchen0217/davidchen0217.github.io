Linux SSH 金鑰登入：ssh-keygen 產生金鑰、ssh-copy-id 免密碼登入，以及查詢登入成功與失敗紀錄

發表於 2021-01-22 更新於 2026-11-27 分類於 Linux 閱讀次數： Disqus： 文章字數： 1.5k 所需閱讀時間 ≈ 3 分鐘

用公開金鑰認證（Public Key Authentication）登入 Linux，不用每次輸入密碼，也比密碼登入安全。這篇整理用 ssh-keygen 產生金鑰、用 ssh-copy-id 把公鑰放到伺服器上完成免密碼登入，以及用 log 查詢誰登入成功、誰登入失敗。

公鑰與私鑰

檔案說明
id_rsa.pub（公鑰）可以公開，要放到遠端 Linux 伺服器上做認證
id_rsa（私鑰）必須保護好，等同於你的密碼，只放在自己的電腦

伺服器用你的公鑰出題、你的電腦用私鑰作答，私鑰從頭到尾都不會在網路上傳送。

Step 1：產生金鑰

先建立 ~/.ssh 目錄並設定正確權限：

用 ssh-keygen 產生金鑰：

完成後會產生：

  • /home/user/.ssh/id_rsa.pub：公鑰
  • /home/user/.ssh/id_rsa：私鑰（Windows 上的 PuTTY 可以用 PuTTYgen 把它轉成 .ppk 格式）

新版 OpenSSH 建議改用更短、更安全的 Ed25519：ssh-keygen -t ed25519。替私鑰設定 passphrase，可以避免私鑰檔案外流時被直接拿來登入。

Step 2：把公鑰放到伺服器，完成免密碼登入

這時需要輸入一次這台伺服器的密碼。ssh-copy-id 會把你的公鑰附加到伺服器上的 ~/.ssh/authorized_keys，並設定好權限。之後再 ssh root@xxx.xxx.xxx.xxx 就不用輸入密碼了。

如果還是要求輸入密碼，通常是伺服器上的權限不對：

金鑰登入設定好之後，可以考慮在伺服器的 /etc/ssh/sshd_config 設定 PasswordAuthentication no，完全關閉密碼登入，杜絕暴力破解（設定前務必確認金鑰登入已經成功，避免把自己鎖在外面）。
