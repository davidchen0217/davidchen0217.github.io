迭代器模式（Iterator）：不暴露內部結構就能走訪集合，以及 .NET 的 IEnumerator 與 foreach

發表於 2024-11-07 更新於 2026-11-27 分類於 ObjectOrientedProgramming 閱讀次數： Disqus： 文章字數： 1.7k 所需閱讀時間 ≈ 3 分鐘

這篇是《大話設計模式》迭代器模式的讀書筆記：迭代器模式的定義與使用時機、.NET 用 IEnumerator 和 IEnumerable 兩個介面實現迭代器，以及 foreach 在背後其實就是在使用迭代器。

定義

迭代器模式：提供一種方法依序存取一個聚合物件中的各個元素，而又不暴露該物件的內部表示。

什麼時候使用

  • 需要存取一個集合物件，而且不管集合裡是什麼，都需要走訪全部元素時
  • 需要用多種方式走訪同一個集合時（例如從前往後、從後往前）
  • 想替走訪不同的集合提供統一的介面：開始、下一個、是否結束、目前是哪一個

迭代器模式把集合物件的走訪行為分離出來，交給一個迭代器類別負責。這樣既不會暴露集合的內部結構，又能讓外部程式碼透明地存取集合裡的資料。

Java 的對照

Java 對應的是 Iterator（hasNext()、next()）和 Iterable 介面，加強版的 for (String item : list) 背後同樣是在使用 Iterator。走訪時要刪除元素，必須用 iterator.remove()，直接呼叫 list.remove() 會拋出 ConcurrentModificationException。
