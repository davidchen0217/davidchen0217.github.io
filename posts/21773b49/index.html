Linux DNS 設定與排錯：nameserver 設定、Name or service not known、修改網卡 DNS、/etc/hosts 與 dig 指令

ping 網址出現 Name or service not known

錯誤訊息

原因

主機沒有設定 DNS 伺服器，或設定的 DNS 伺服器無法使用，網址無法被解析成 IP。可以先用 ping 8.8.8.8 確認：能 ping 通 IP、但 ping 不通網址，就是 DNS 的問題。

解法

在 /etc/resolv.conf 加上 DNS 伺服器：

設定多組 nameserver

DNS 伺服器的 IP 可以設定多個，當作備援：第一部（依設定順序）掛掉時，用戶端會改用第二部查詢。

8.8.8.8 是 Google 的 DNS，1.1.1.1 是 Cloudflare 的 DNS。

  • 建議至少設定兩部
  • 網路正常時，永遠只會用第一部查詢，後面的只有在第一部沒有回應時才會用到
  • 不要設定超過 3 部：系統最多只會讀前 3 個 nameserver；而且如果是區網本身出問題，主機會依序對每一部 DNS 發出查詢，每一部都要等到 timeout，反而浪費很多時間

修改網卡的 DNS 設定（避免 resolv.conf 被覆蓋）

/etc/resolv.conf 開頭如果有 # Generated by NetworkManager，代表這個檔案是 NetworkManager 自動產生的，直接修改它，重開機或重啟網路後就會被蓋掉。要永久修改，應該改網卡的設定。
