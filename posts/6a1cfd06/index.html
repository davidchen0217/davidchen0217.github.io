Chrome 110 起 User-Agent 固定為 Android 10; K：User-Agent Reduction 與用 Client Hints 取得裝置型號和版本

發表於 2023-07-06 更新於 2026-11-27 分類於 Chrome 閱讀次數： Disqus： 文章字數： 1.8k 所需閱讀時間 ≈ 3 分鐘

Chrome 110 起，Android 上的 User-Agent 字串不再包含真正的 Android 版本和裝置型號，而是固定回傳 Android 10; K。依賴 User-Agent 做裝置統計或相容性判斷的系統會因此失準。這篇說明 User-Agent Reduction 改了什麼，以及如何改用 User-Agent Client Hints（HTTP header Sec-CH-UA-* 或 JavaScript navigator.userAgentData）取得詳細資訊。

User-Agent 改了什麼

為了保護隱私（User-Agent 裡的細節可以拿來做瀏覽器指紋追蹤），Chrome 逐步推行 User-Agent Reduction。從 Chrome 110 開始，Android 的 User-Agent 字串固定回傳：

  • Android 版本：Android 10
  • 裝置型號：K

所有 Android 裝置看起來都一樣，從 User-Agent 已經無法分辨使用者的 Android 版本和手機型號。

改用 User-Agent Client Hints

實務上，產品分析、相容性判斷還是需要詳細的裝置資訊。Chrome 提供了 User-Agent Client Hints（UA-CH），可以透過 HTTP header 或 JavaScript 取得。

實務上要注意

  • 只有 Chromium 系列的瀏覽器支援（Chrome、Edge、Opera 等），Safari 和 Firefox 沒有 navigator.userAgentData，要先判斷是否存在
  • 只在 HTTPS 的網站上可用
  • 原本從 User-Agent 解析裝置資訊的分析工具或後端程式，需要改成讀取 Client Hints；舊資料和新資料的裝置分布會出現斷層，比較報表時要留意
