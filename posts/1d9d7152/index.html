原因

錯誤三：Cannot connect to the Docker daemon

錯誤訊息

原因

Docker daemon 沒有在執行。最常見的情況是：安裝完只有 start 沒有 enable，機器重開機後 Docker 就沒有自動啟動。

解法

如果 daemon 有在執行，但一般使用者執行 docker 出現的是 permission denied while trying to connect to the Docker daemon socket，那是權限問題：把使用者加入 docker 群組（sudo usermod -aG docker $USER），重新登入後即可。
