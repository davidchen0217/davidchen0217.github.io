CloudFlare Set Domain To GitHub Pages

發表於 2021-09-12 分類於 CloudFlare 閱讀次數： Disqus： 文章字數： 232 所需閱讀時間 ≈ 1 分鐘

Step by step:

1.先去購買自己喜歡的domain
2.CloudFlare註冊帳號 -> add site -> 填入剛購買的domain
3.在domain購買網站輸入 DNS Servers -> 通常有兩組 xxx.ns.cloudflare.com
4.這邊需要等待時間讓DNS Server設定生效
5.至GitHub Pages 設定 Custom Domain
6.$ ping {domain}
7.$ dig {domain}
6 & 7可確認domain設定是否生效
